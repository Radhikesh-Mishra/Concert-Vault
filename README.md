# Concert Vault

Concert Vault is a simple, responsive UI website for buying concert tickets for upcoming concerts. Users can explore upcoming concerts and purchase tickets, while admins can upload new concerts. The app is built using the **MERN stack** (MongoDB, Express, React, Node.js) and **Bootstrap** for styling.

---

## Features

- **User Features**:
  - View upcoming concerts.
  - Buy tickets for concerts.
  - Receive confirmation emails after ticket purchase.

- **Admin Features**:
  - Upload and manage upcoming concerts.
  
---

## Tech Stack

- **Frontend**:
  - React.js
  - Bootstrap

- **Backend**:
  - Node.js with Express.js
  - MongoDB
  - Nodemailer for email notifications
